## 1. 범위

DEM 경사 분석과 머신러닝 예측으로 개인 낙상위험과 지역 보행환경 위험을 산출해
고령자와 기초자치단체에 제공하는 웹 서비스.

| 구분 | 제공 기능 |
|---|---|
| 개인용 | 간편 확인, 심층 확인, 개인 리포트, 경로 경사도 확인 |
| 기관용 | 보행 경사위험도 지도, 위험 상위 순위, 행정동 상세, 투입 효과 기대 지역 |

지역 분석 범위는 서울특별시. 생활인구와 보행로 경사 자료가 서울에 한정됨.

## 3. 개인용 기능 상세

### F-02 간편 등록

수집 항목 4종.

| 항목 | 형식 | 검증 |
|---|---|---|
| 이름 | 문자열 | 공백 불가 |
| 생년월일 | 숫자 8자리 | 연도 1900~당해, 월 1~12, 일 1~31 |
| 생년월일 확인 | 숫자 8자리 | 1차 입력과 일치 |
| 성별 | 남성·여성 택1 | 선택 필수 |
| 최근 1년 낙상 경험 | 있음·없음 택1 | 선택 필수 |

- 생년월일 2회 입력은 오타 방지 목적. 불일치 시 입력란에 오류 표시
- 4종 모두 충족해야 진행 버튼 활성화
- 낙상 경험 값은 재발위험 모델의 실행 여부를 결정

### F-03 만 나이 자동 계산

- 생년월일에서 생일 경과 여부를 반영해 만 나이 산출
- 간편 확인의 연령 문항에 자동 입력. 이용자가 다시 입력할 필요 없음
- 형식이 맞지 않으면 값을 비워 두고 직접 입력을 허용

### F-05 간편 확인

- 문항 6개: 성별, 연령, 처방약 종류수, 1년내 입원, 주관적 건강상태, 이동보조기
- 1문항 1화면. 상단 진행바로 위치 표시
- 성별과 연령은 등록 정보에서 자동 입력
- 결과 화면 구성: 낙상 위험 게이지, 재발 위험 점수, 등급 배지, 안내 문구, 주요 위험요인 목록

### F-06 심층 확인

문항 42개를 4개 묶음으로 구성.

| 묶음 | 문항 수 | 내용 |
|---|---|---|
| 기본 정보 | 10 | 간편 6문항 + 외래이용, 수면의 질, 시력, 청력 |
| 신체 기능 | 14 | 이동 불편, 피로, 계단, 보행거리 + 일상생활 수행 10문항 |
| 질환·마음 | 6 | 만성질환 선택 1문항 + 우울 척도 5문항 |
| 영양 상태 | 12 | 영양 위험 문항 12개 |

- 만성질환은 16종 다중 선택 1문항으로 수집. 해당 없음 선택지 별도 제공
- 진행 위치를 좌측 단계 안내와 상단 구간 진행바에 이중 표시
- 25%, 50%, 75%, 종료 직전 지점에서 격려 문구 노출

### F-07 응답 자동 저장과 이어하기

- 문항 응답 시마다 초안을 저장
- 재진입 시 초안을 복원해 중단 지점부터 진행
- 확인 완료 또는 다시 하기 선택 시 초안 삭제
- 기록 지우기 실행 시 결과 기록과 초안을 함께 삭제

### F-08 간편 응답 승계

- 심층 확인 진입 시 간편 확인 기록을 조회
- 기록이 있으면 공통 6문항을 복사하고 7번째 문항부터 시작
- 화면에 남은 36문항 안내 표기
- 심층 확인 완료 시 공통 6문항으로 간편 예측을 다시 실행해 간편 기록도 갱신

### F-09 · F-10 위험 예측

머신러닝 담당이 확정한 학습 결과물을 그대로 사용. 서비스는 응답 변환과 호출만 담당.

| 조합 | 알고리즘 | AUC | 판정 임계값 |
|---|---|---|---|
| 낙상위험 · 간편 | LightGBM | 0.760 | 0.30 |
| 낙상위험 · 심층 | Random Forest | 0.787 | 0.40 |
| 재발위험 · 간편 | Random Forest | 0.666 | 0.25 |
| 재발위험 · 심층 | Random Forest | 0.700 | 0.20 |

- 낙상위험 모델은 전체 이용자 대상. 항상 실행
- 재발위험 모델은 낙상 경험자 전용. 등록 시 수집한 낙상 경험 값으로 실행 여부 결정
- 응답 형식이 맞지 않으면 422, 모델 미적재 상태면 503 반환

### F-11 영향요인 제시

- SHAP 기여도 상위 5개 항목을 산출
- 각 항목에 위험 방향(증가·감소)과 한글 라벨을 부여
- 간편 확인 결과 화면과 심층 확인 결과 화면에 노출

### F-12 6영역 프로파일

응답으로 계산하는 영역 점수 6종. 값이 클수록 위험이 큼.

| 영역 | 계산 근거 |
|---|---|
| 신체 기능 | 이동 불편, 피로, 계단, 보행거리, 시력·청력(가중 0.5) 평균 |
| 질환 부담 | 질환 수 × 15 + 입원 10 + 외래이용 5, 상한 100 |
| 약물 복용 | 처방약 종류수 × 12, 상한 100 |
| 영양 상태 | 영양 위험 점수를 21점 만점 대비 백분율로 환산 |
| 정서·마음 | 우울 점수 × 18 + 수면의 질 보정 |
| 일상생활 수행 | 일상생활 수행 총점의 백분율 + 이동보조기 15 |

- 총점은 6영역 단순 평균
- 등급 경계: 33점 이하 양호, 34~66점 주의, 67점 이상 위험

### F-13 리포트

- 6영역 레이다 차트, 영역별 막대와 안내 문구를 배치
- 심층 확인 기록이 없으면 안내 카드를 표시하고 허브로 복귀 버튼 제공
- 브라우저 인쇄 기능으로 PDF 저장

### F-14 · F-15 · F-16 경로 경사도

처리 순서:

1. 장소명 또는 주소로 출발지·도착지 검색
2. 보행자 경로 탐색
3. 경로 좌표를 30m 간격으로 재배치
4. 각 지점을 보행로 지점에 스냅해 실측 경사 부여
5. 스냅 성공률이 60% 미만이면 위성 고도모델로 대체 산출

- 경사 크기는 보행로 실측값, 오르막·내리막 방향은 표고 흐름에서 산출
- 자동차 경로 미제공. 고령자 보행 안전이 목적이므로 대상에서 제외
- 결과 표시: 총 거리, 예상 시간, 평균 경사, 최대 경사, 경로 지도, 고도 그래프, 구간 경사 막대, 구간 데이터 표

경사 구간 색 구분 5단계.

| 구간 | 의미 |
|---|---|
| 0~3.2° | 권장기준 이내 |
| 3.2~4.8° | 권장 초과 |
| 4.8~8° | 완화 한도 초과 |
| 8~12° | 가파름 |
| 12° 이상 | 매우 가파름 |

경사 출처를 화면에 명시. 실측 스냅 구간 수 또는 고도모델 대체 여부를 표기.

### F-17 · F-18 날씨와 기상특보

- 출발지와 이동 날짜가 정해지면 자동 조회
- 표시 항목: 날씨 설명, 최고·최저 기온, 강수량, 강수확률, 보행 주의 문구
- 보행 주의 등급 3단계를 카드 좌측 색으로 표시
- 발효 중 기상특보가 있으면 지도 위에 배너 노출
- 대설·한파는 결빙 경고 문구, 그 외 특보는 일반 주의 문구

### F-19 로드뷰 연결

- 카카오맵 로드뷰를 새 탭으로 연결. 별도 키 불필요
- 경로 화면: 구간, 급경사 라벨, 지도 임의 지점
- 대시보드: 위험 상위 표, 투입 효과 기대 지역 표, 행정동 상세
- 대시보드의 좌표는 행정동 중심이 아니라 가장 가파른 지점. 중심점은 큰길이라 평지인 경우가 많아 현장 확인에 부적합

## 4. 기관용 기능 상세

### F-20 · F-21 보행 경사위험도 지도

- 1단계 자치구 25개, 2단계 행정동 단위 드릴다운
- 서울 400여 개 동을 한 화면에 그리면 색 구분이 불가능해 단계를 나눔
- 이름 라벨은 기본 꺼짐. 배경지도의 상호·도로명과 겹쳐 가림
- 자료가 부족한 구역은 회색. 위험이 낮다는 뜻이 아니라 판단 근거가 없다는 뜻

등급 구분.

| 등급 | 점수 | 대응 기준 |
|---|---|---|
| 양호 | 33점 미만 | 평균 경사가 권장 기울기 1/18 미만 |
| 주의 | 33~49점 | 권장 초과, 완화 한도 이내 |
| 위험 | 50점 이상 | 평균 경사가 완화 한도 1/12 초과 |

### F-22 위험 상위 순위표

- 지도의 드릴다운 단계를 따라감. 서울 전체에서는 자치구, 구를 열면 그 구의 행정동
- 등급 필터 제공(전체·위험·주의·양호)
- 행 선택 시 지도와 상세 카드가 연동

### F-23 행정동 위험 프로필

표시 항목 6종.

| 항목 | 분모 |
|---|---|
| 평균 경사 | 분석 지점 전체 |
| 최대 경사 | 분석 지점 전체 |
| 기준 초과 지점 수 | 분석 지점 전체 |
| 협소 구간 수 | 폭이 기록된 지점 |
| 보도 폭 평균 | 폭이 기록된 지점 |
| 미끄러운 노면 지점 수 | 재질이 기록된 지점 |

- 세 종류의 분모가 서로 달라 비율 대신 개수로 표기하고 각 줄에 분모를 함께 명시
- 폭·재질 기록이 10개 미만인 행정동은 수치를 감추고 자료 부족 사실을 표기

### F-24 · F-25 인구 연계

- 인구 지표: 총인구, 인구밀도, 평균나이, 노령화지수. 통계청 자료
- 시간대별 생활인구: 0시부터 23시까지 24개 구간. 서울 자료
- 생활인구는 공개 지연 기간이 고정되지 않아, 요청 날짜부터 과거로 훑어 자료가 있는 최근 날짜를 사용
- 조회 실패 시 값을 지어내지 않고 자료 없음과 실패 사유를 표기

### F-26 투입 효과 기대 지역

- 산식: 보행 경사위험도 × 일평균 생활인구 ÷ 1,000
- 상위 12개 행정동을 제시
- 위험 상위 순위와의 차이는 노출 인구 반영 여부
- 가정: 경사가 가파를수록, 통행량이 많을수록 같은 정비 예산으로 줄일 수 있는 낙상 건수가 큼

### F-27 산출 근거 공개

페이지 최하단에 산식, 효과지수, 등급, 자료 출처를 배치하고 질문 8건을 접힘 상태로 제공.

| 질문 | 답변 요지 |
|---|---|
| 경사 측정 방식 | 지형 경사가 아니라 길을 따라간 종단경사, 90m 구간 평균 |
| 등급 경계 근거 | 장애인등편의법 시행규칙 별표1 접근로 기울기에서 역산 |
| 로드뷰가 평지로 보이는 경우 | 상위 5% 지점 지정, 표고모델 해상도 한계 |
| 등산로 제외 사유 | 생활 낙상과 무관, 평균을 끌어올림 |
| 회색 구역의 의미 | 판단 자료 부족 |
| 폭 자료 결측 | 기록률 26.7%, 가중평균 대신 가산으로 반영 |
| 재질을 점수에서 제외한 사유 | 측정값이 아니라 재질별 고정 매핑 |
| 계단·다리·터널 | 계단 미포함, 다리·터널 보정은 준비 상태 |

본문 카드에는 수치만 배치. 설명 문구를 화면 곳곳에 흩으면 읽는 사람이 없고
근거를 찾는 사람은 한 곳에서 몰아 읽는 편이 나음.

## 5. 지역 위험도 산출 로직

산출 스크립트: `scripts/build_risk_geojson.py`, `scripts/longitudinal_slope.py`.
산출물은 정적 자산으로 배포되며 실행 시점에 계산하지 않음.

### 5.1 입력

- 보행로 지점 185,114개. 20m 간격 표본
- 도로유형 footway·pedestrian만 사용. path는 제외
- 제외 근거: path 47,309개가 전부 등산로이며 평균 경사 10.9°로 생활 보행로 2.4°보다 크게 높음[^1]

### 5.2 종단경사 재계산

원본 자료의 경사 값은 그 자리 지형의 경사이므로 그대로 사용하지 않음.

- 지점 순서를 최근접 이웃으로 복원해 길을 따라간 순서를 만듦
- 90m 구간의 평균 기울기를 산출. 표고모델 격자 30m의 3배
- 60m 넘게 벌어진 지점 사이는 끊어서 계산

산비탈을 비스듬히 가로지르는 길은 지형 경사와 종단경사가 크게 다름[^2].

### 5.3 산식

```
상시부담   = min(1, 평균 경사 ÷ 4.76°)
기준초과   = 4.76° 넘는 지점의 비율
경사점수   = 100 × (0.5 × 상시부담 + 0.5 × 기준초과)
보행위험도 = min(100, 경사점수 + 협소 비율 × 40)
```

- 4.76°는 장애인등편의법 시행규칙 별표1의 접근로 기울기 완화 한도 1/12
- 협소는 폭 1.5m 이하. 국토교통부 보도 설치 및 관리 지침의 유효폭 기준
- 협소 가산 계수 40은 팀 계층분석 결과의 경사 대 협소 비율을 유지한 값[^3]
- 폭 기록이 10개 미만인 행정동은 가산하지 않음
- 노면 재질은 점수에 미반영. 측정값이 아니라 재질별 고정 매핑이기 때문

### 5.4 가중평균을 쓰지 않은 이유

원본 방식인 가중 평균을 그대로 적용하면 위험도가 내려감.

- 폭이 기록된 지점이 26.7%뿐이라 협소 비율의 중앙값이 0.0%
- 그 0이 가중 평균에서 점수를 26% 희석
- 실제 계산 시 306개 동 중 62개의 등급이 하락하며 전부 협소 값이 0인 곳[^4]

### 5.5 다리·터널 보정

- 표고모델은 지표면 모델이므로 다리 아래 지면과 터널 위 산을 읽음
- 해당 구간은 양끝 표고를 이어 일정 기울기로 대체
- 서울 생활 보행로 31,695개 중 1,605개(5.1%)가 해당
- 보정 코드는 반영 완료. 산출물 갱신 시 함께 적용
